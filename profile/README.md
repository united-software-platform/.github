# Декларация сообщества United Software Platform

## Общие принципы

United Software Platform — это сообщество разработчиков, созданное для обмена знаниями, опытом и наработками.

Это открытая среда для сотрудничества и взаимной поддержки.

## Коммерция

Внутри сообщества участники не продают друг другу услуги или продукты и не используют площадку для поиска клиентов.

При этом сообщество может создавать и продавать решения коммерческим организациям.

## Свободный обмен

Участники делятся тем, что у них есть:

* знаниями;
* кодом;
* инструментами;
* опытом и практиками.

Внутри сообщества всё передаётся добровольно и безвозмездно.

## Культура взаимодействия

Основа сообщества:

* открытость;
* взаимопомощь;
* честность;
* профессиональное уважение.

Каждый участник не только получает, но и вносит вклад.

## Назначение

United Software Platform — это пространство для свободного обмена знаниями и совместного роста без внутренней коммерции.
